## 콜아웃

콜아웃은 `:::종류` 로 시작하고 `:::`로 닫습니다. 종류는 `note`, `tip`, `warning`, `caution`, `important` 다섯 가지입니다.

:::note
기본 콜아웃입니다. 제목은 종류 이름이 자동으로 붙습니다.
:::

:::tip
**팁**: 콜아웃 안에서도 `서식`과 [링크](https://astro.build)를 쓸 수 있습니다.
:::

:::warning
주의가 필요한 내용에 씁니다.
:::

:::caution
되돌릴 수 없는 작업처럼 위험한 내용에 씁니다.
:::

:::important
꼭 알아야 하는 내용에 씁니다.
:::

대괄호로 제목을 덧붙일 수 있습니다.

:::note[제목이 있는 콜아웃]
종류 이름 옆에 괄호로 제목이 함께 표시됩니다.
:::

`{closed}`를 붙이면 접힌 상태로 시작합니다. 길어서 숨겨 두고 싶은 내용에 쓰세요.

:::tip[접힌 콜아웃]{closed}
클릭하면 펼쳐집니다.

콜아웃 안에는 목록과 코드도 넣을 수 있습니다.

- 첫째
- 둘째

```bash
pnpm install
```
:::

:::warning[에디터 주의]
리치 텍스트 에디터의 **Editor 탭**에서 저장하면 제목이 있는 콜아웃의 대괄호가 깨질 수 있습니다. 제목이 있는 콜아웃은 마크다운 편집기나 Source 탭에서 쓰세요.
:::

## 코드 블록

코드 블록은 [Expressive Code](https://expressive-code.com/)로 표시됩니다. 줄 번호는 기본으로 켜져 있고, 셸 명령은 꺼져 있습니다.

### 파일 이름 붙이기

````markdown
```ts title="src/lib/greet.ts"
````

```ts title="src/lib/greet.ts"
export function greet(name: string) {
  return `안녕하세요, ${name}님!`
}

console.log(greet("세계"))
```

### 줄 강조, 추가, 삭제

중괄호에 줄 번호를 넣으면 강조되고, `ins`는 추가된 줄, `del`은 삭제된 줄로 표시됩니다.

```ts title="강조: {2,4-5}" {2,4-5}
const fruits = ["사과", "배", "귤"]
fruits.push("포도")
console.log(fruits)
fruits.sort()
console.log(fruits)
```

```ts title="추가와 삭제: ins={3} del={2}" ins={3} del={2}
const config = {
  mode: "development",
  mode: "production",
}
```

### 특정 글자 표시

따옴표로 감싼 글자나 정규식에 일치하는 부분이 표시됩니다.

```ts title='글자 표시: "hello"' "hello"
const message = "hello"
console.log(message, "hello again")
```

### 긴 코드 접기

`collapse`로 지정한 줄은 접혀서 나타납니다. 중요하지 않은 import나 설정을 숨길 때 좋습니다.

```ts title="src/pages/api.ts" collapse={1-5, 12-14}
import { a } from "./a"
import { b } from "./b"
import { c } from "./c"
import { d } from "./d"
import { e } from "./e"

export function run() {
  const result = a() + b()
  console.log(result)
  return result
}

function unused() {
  return c() + d() + e()
}
```

### 줄 번호 조절

시작 번호는 `startLineNumber`, 끄는 것은 `showLineNumbers=false`입니다.

```py title="파이썬 예시 (100번 줄부터)" startLineNumber=100
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

```json title="줄 번호 없이" showLineNumbers=false
{
  "name": "sample",
  "private": true
}
```

### 터미널과 diff

`bash` 같은 셸 언어는 터미널 모양으로 표시됩니다.

```bash
pnpm install
pnpm dev
```

`diff` 언어를 쓰면 변경 내용을 그대로 보여 줄 수 있습니다.

```diff
- const total = price * count
+ const total = price * count * (1 + taxRate)
```

## 인라인 코드 하이라이트

인라인 코드 끝에 `{:언어}`를 붙이면 그 언어로 색이 입혀집니다. 예를 들어 `const x = 1{:ts}`나 `print("hi"){:py}`처럼 씁니다.

`{:.scope}` 형식으로 테마의 색 이름을 지정할 수도 있습니다. `"문자열처럼 보이게"{:.string}`, `42{:.constant.numeric}` 같은 식입니다.
